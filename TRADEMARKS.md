# Project name and attribution

“AProDB” identifies the original Adaptive Parallel Object Database project created by Andrea Provenzali. No statement in this repository represents that the name is a registered trademark.

Truthful references to AProDB, compatibility statements, and unmodified redistributions are welcome. Modified versions and forks must not imply they are official, approved, or maintained by the original project when that is not true. A substantially modified public fork should use a distinct product name while preserving the copyright and origin notices required by its license.

This project-name policy is separate from the software licenses and does not restrict otherwise lawful descriptive use.
