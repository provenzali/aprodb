# Security policy

## Supported status

AProDB is currently in **beta testing** and is not production-ready. There is no security-support SLA and no release line is yet guaranteed to receive patches.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for the canonical repository:

<https://github.com/provenzali/aprodb/security/advisories/new>

Do not include secrets, production datasets or exploit details in a public issue. Include the affected revision, configuration, reproduction steps, impact, and any proposed mitigation. The maintainer will acknowledge receipt through the private advisory when available.

The absence of a public report does not imply that a finding is fixed. Consult the advisory or release notes before deploying a later build.
